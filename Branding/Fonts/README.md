# Menu font

The active menu font is **Teko SemiBold**, static weight 600, from the official
Google Fonts Teko repository. See `Teko/README.md` for the user-supplied package,
source, static-instance generation and SIL OFL 1.1 redistribution details.

The game stages the font and full license locally; it needs no font download.

The retained `BarlowCondensed-SemiBold.ttf` prototype is unused at runtime.
Copyright 2017 The Barlow Project Authors; its SIL OFL 1.1 notice is `OFL.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
